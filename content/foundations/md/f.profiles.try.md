Field Academy has set up two practice profiles, `academy-practice` and `academy-practice-b`. Pretend each one works for a different client. The mission page has a button for each: **Open practice chat A** opens a new chat in `academy-practice`, and **Open practice chat B** opens one in `academy-practice-b`. Field Academy has also put a short notes file in a practice folder; the mission page shows its full path, with a copy button.

1. **Save a fact in A.** Press **Open practice chat A**. Send: `Save this to memory: the Hollis report is due on the 14th.` Check the activity rows for the memory save.
2. **Ask B.** Press **Open practice chat B**. Before you send, predict the answer. Then send: `When is the Hollis report due?`
3. **Ask B to read a file.** In the same B chat, predict again, then paste the path from the mission page into this message and send it: `Open the file at <path> and tell me the deadline it gives.`

Write down both answers.

If you guessed B would know all of it, or none of it, you got neither. B has never heard of the report, then opens the file and reads you the deadline.
