Field Academy has put three meeting notes in the practice folder, under `meetings/`. Every toolset Hermes ships is
switched on in this practice profile, as it is in a new one.

1. **Look at what it has.** Open **Capabilities**, set **Configuring:** to `academy-practice`, and go to the **Tools**
   tab. Count the toolsets that are on.
2. **Your guess.** You're about to ask Hermes to run a command in the terminal. The job you'll give it later only
   reads three notes and writes one page. Will it run the command? Write yes or no.
3. **Ask.** Press **Open practice chat** and send: `Run the command date in the terminal.`

A job that only reads and writes notes has no use for a terminal, so no is a fair guess. Hermes runs it. It runs
anything the toolsets that are on allow, whatever the job is, until you switch them off.
