The practice folder has a file called `notes.md` with a few lines of meeting notes. Field Academy keeps an untouched
copy in the folder's `originals` folder, so nothing here is lost for good.

1. Press **Open practice chat**. Type this, with the practice folder's location from the mission page where it says
   *folder*, but don't send it yet:

   `Replace everything in` *folder*`/notes.md with the single word DRAFT.`

2. Write two guesses. Will Hermes ask you before it changes the file? If you don't like the result, can you undo it?

3. Send it. Watch the activity rows while it works, then open `notes.md`.

4. Type `/rollback` and send it.

If you guessed a question before the change or an undo after, look at what you got. The file changed and nobody asked.
`/rollback` had nothing to give back. In a new profile that's the usual result, and the rest of this mission is about
why.

Before you read on, find the **Working folder** line on the mission page. Field Academy reads it from the chat you
just had, and it shows a pass or a fail. You'll need a pass later, when `/rollback` goes looking for snapshots. If it
says fail, the fix is in the Checkpoints section below.

Put the notes back by asking Hermes to copy *folder*`/originals/notes.md` over *folder*`/notes.md`, then read on.
